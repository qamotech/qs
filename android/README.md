# Qamelot Studio - Android Native Wrapper

This directory contains the Capacitor-based Android project for Qamelot Studio.

## 🚀 Building the APK

1.  **Sync Capacitor**:
    ```bash
    npx cap sync android
    ```

2.  **Open in Android Studio**:
    Open this folder (`/android`) in Android Studio to build, debug, and deploy to a physical device or emulator.

3.  **Command Line Build**:
    ```bash
    ./gradlew assembleDebug
    ```

## 📱 Hardware Features
- **Hardware Acceleration**: Enabled for high-performance audio processing.
- **Orientation**: Optimized for Landscape mode.
- **Audio Latency**: Low-latency configuration for real-time synthesis.
