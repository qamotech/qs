This plan will integrate Capacitor into the React/Vite project, allowing you to generate an Android APK directly from your web assets.

## Tasks

1.  **Install Capacitor dependencies**: `@capacitor/core`, `@capacitor/cli`, and `@capacitor/android`.
2.  **Build the Web App**: Run `npm run build` to generate the `dist` folder.
3.  **Initialize Capacitor**: Run `npx cap init`.
4.  **Add Android Platform**: Run `npx cap add android`.
5.  **Sync Assets**: Run `npx cap sync`.
6.  **Build APK**: Run `./gradlew assembleDebug` inside the `android/` directory.
